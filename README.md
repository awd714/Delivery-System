# Быстрая доставка

Учебное приложение для учёта клиентов и заказов. Python 3.8+, SQLite, Tkinter. Поддерживается импорт и экспорт JSON.

## Запуск

Откройте папку проекта в VS Code и терминал в этой папке. Для запуска приложения дополнительные пакеты не нужны. В Linux может потребоваться системный пакет `python3-tk`.

```bash
python main_gui.py
```

В Windows вместо `python` можно использовать `py` или полный путь к интерпретатору Python.

## Работа с приложением

1. Нажмите «Клиенты» → «Добавить», укажите имя, телефон и адрес. Здесь же можно редактировать и удалять клиентов. Клиента с заказами удалить нельзя.
2. В главном окне нажмите «Добавить». Выберите клиента, дату и статус заказа. Товары указываются по одному на строку в формате `название|количество|цена`, например:

   ```text
   Пицца|2|750
   Чай|1|100
   ```

   Итоговая сумма рассчитывается автоматически (1600.00). Нажмите «Сохранить».
3. Для редактирования или удаления выделите заказ в таблице и нажмите соответствующую кнопку.
4. Для фильтрации выберите статус или укажите диапазон дат в формате `ГГГГ-ММ-ДД`. Нажмите «Фильтр». «Сбросить» показывает все заказы.
5. Для отчёта нажмите «Показать отчёт», выберите период и нажмите «Обновить».

Данные сохраняются в `data/delivery.db`. База изначально пустая.

## Консольный режим

```bash
python main_cli.py report --period day
python main_cli.py report --period week
python main_cli.py report --period month
python main_cli.py export --file orders.json
python main_cli.py import --file orders.json
python main_cli.py --help
```

Вместо `main_cli.py` также можно использовать `delivery.py`.

Количество заказов по статусам и топ-3 клиента рассчитываются за всё время по всем заказам. Выручка учитывает только выполненные заказы: за сегодня, с начала текущей недели (понедельник) или месяца по сегодня включительно.

## Импорт и экспорт

Экспорт сохраняет все заказы, товары и сведения о связанных клиентах в JSON. Пример файла:

```json
{
  "orders": [
    {
      "id": 1,
      "customer_id": 1,
      "order_date": "2026-11-26",
      "status": "новый",
      "total": 1500.0,
      "items": [{"product_name": "Пицца", "quantity": 2, "price": 750}],
      "customer": {"id": 1, "name": "Иван", "phone": "123", "address": "Москва"}
    }
  ]
}
```

При импорте проверяются структура, дата, статус, клиент, товары и итоговая сумма. Совпадающие заказы не добавляются повторно. При конфликте идентификаторов или ошибке весь импорт отменяется. Если сведения о клиенте отсутствуют, клиент с указанным ID должен уже существовать. Клиенты без заказов не экспортируются.

## Тестирование

Установите зависимости для тестирования и запустите pytest:

```bash
python -m pip install -r requirements.txt
python -m pytest
python -m pytest --cov=. --cov-report=term-missing --cov-fail-under=60
```

Тесты используют временные базы и файлы. Тесты Tkinter запускаются при наличии графического экрана; без экрана они пропускаются. На Linux можно использовать `xvfb-run -a python -m pytest`.

## Структура

- `main_cli.py`, `delivery.py` — консольный режим.
- `main_gui.py` — графический интерфейс.
- `database.py` — операции SQLite и отчёты.
- `models.py` — классы Customer и Order, проверка данных.
- `data_export.py` — импорт и экспорт JSON.
- `logger_config.py` — настройка журналирования.
- `logs/` — журнал `delivery.log`, создаваемый при запуске.
- `data/` — база данных.
- `tests/` — тесты pytest.
- `requirements.txt` — зависимости тестов.

XML, TinyDB и кнопки импорта/экспорта в GUI не реализованы. Для обмена файлами используется CLI. Не публикуйте реальные данные клиентов или рабочие резервные копии в открытом репозитории.
